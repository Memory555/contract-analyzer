# 合同智能分析平台 UI 设计说明文档

版本：V1.0  
日期：2026-06-17  
当前原型：`D:\feidu\工具1\contract-analyzer\design\prototypes\low_fidelity_wireframe_v2_nav.svg`

## 1. 设计目标

合同智能分析平台采用可扩展的后台工作台形态，而不是单一上传工具页。

当前版本聚焦“单合同分析”，但 UI 结构需要为后续扩展更多合同处理能力预留空间，例如批量分析、问题审查、导出中心、字段配置、模型配置和历史记录。

设计风格以专业、清晰、美观为主，避免营销化首页。用户进入系统后应直接看到可操作的合同分析工作台。

## 2. 品牌与视觉方向

| 项目 | 设计说明 |
|------|----------|
| Logo | 使用“飞渡 Logo”占位符，后续替换正式品牌资产 |
| 风格 | 办公系统 / 后台工作台风格 |
| 色彩 | 以深色导航栏、浅色内容区、蓝色主操作色为基础 |
| 视觉重点 | 上传入口、解析状态、合同问题提示、结构化结果、Excel 下载 |
| 页面密度 | 中高信息密度，适合合同管理和项目助理反复使用 |

建议主色为稳重蓝色，辅助色用于风险分级：

| 类型 | 建议颜色含义 |
|------|--------------|
| 主操作 | 蓝色，用于上传、下载、当前导航高亮 |
| 错误 | 红色，用于严重条款矛盾、关键数值缺失 |
| 警告 | 橙色，用于潜在逻辑冲突、需人工复核问题 |
| 提示 | 灰蓝色或浅蓝色，用于定义模糊、补充建议、低风险提醒 |

## 3. 整体布局

采用左侧导航 + 顶部标题区 + 主内容区的结构。

### 3.1 左侧导航

左侧导航用于承载当前功能和未来扩展功能。

左侧导航支持收缩和展开。展开时显示 Logo、导航图标和文字；收缩时保留 Logo 占位与导航图标，节省横向空间。

| 导航项 | 当前定位 |
|--------|----------|
| 工作台 | 后续用于展示最近任务、统计概览和待处理事项 |
| 合同分析 | 当前核心页面，上传合同并展示分析结果 |
| 问题审查 | 后续聚合所有合同问题，支持人工复核 |
| 导出中心 | 后续管理 Excel 导出记录与模板 |
| 设置 | 后续配置模型、字段、Prompt 和导出模板 |

当前默认高亮“合同分析”。

除“合同分析”外，其他导航项在 Demo 阶段也需要可点击跳转，展示“待进一步开发”的占位页面。

### 3.2 顶部标题区

顶部标题区展示当前页面位置和任务说明：

- 面包屑：合同分析 / 单合同解析
- 页面标题：上传合同并生成结构化分析结果
- 状态标签：V1.0 单合同、无登录

### 3.3 主内容区

主内容区按用户工作流排列：

1. 上传合同
2. 任务摘要
3. 分析结果
4. 合同问题提示
5. 付款计划明细
6. 质保明细
7. Excel 下载配置与下载入口

## 4. 页面模块说明

### 4.1 上传合同模块

支持点击或拖拽上传合同。

基础规则：

- 支持格式：PDF / DOC / DOCX
- 单文件大小：≤ 20MB
- V1.0 每次仅支持 1 份合同

上传模块需要展示以下状态：

| 状态 | 展示方式 |
|------|----------|
| 初始 | 拖拽上传区域 + 文件格式说明 |
| 格式错误 | 上传区红色边框 + 错误提示 |
| 大小超限 | 上传区红色边框 + 大小限制说明 |
| 上传中 | 文件名 + 上传进度条 |
| 解析中 | 进度/加载提示 + “预计 10-30 秒” |

### 4.2 任务摘要模块

任务摘要位于上传区右侧，用于快速反馈当前任务状态。

建议展示：

- 解析状态
- 文件名称
- 文件格式和大小
- 问题数量
- LLM 解析置信度
- 下载 Excel 主按钮

LLM 解析置信度需要展示，但应配合“AI 结果需人工复核”的提示，避免用户误解为确定结论。

### 4.3 合同问题提示模块

合同问题提示保留在结果页顶部，优先展示。

问题严重程度分为三档：

| 严重程度 | 使用场景 |
|----------|----------|
| 错误 | 条款矛盾、关键金额或比例错误、无法执行的逻辑冲突 |
| 警告 | 可能影响履约或后续跟进的问题 |
| 提示 | 定义模糊、表达不够量化、建议补充说明的问题 |

每条问题建议展示：

- 问题类型
- 严重程度
- 问题描述
- 涉及条款位置
- 原文定位入口

### 4.4 合同原文定位 / 条款位置

结果页需要保留“合同原文定位 / 条款位置”能力。

V1.0 可先采用轻量方式：

- 在问题提示和表格行中展示“涉及位置”
- 提供“查看原文位置”入口
- 点击后在侧边抽屉或弹窗中展示对应原文片段

后续如果支持文档预览，可升级为原文高亮定位。

### 4.5 付款计划明细

付款计划采用表格展示。

固定字段包括：

- 阶段序号
- 阶段名称
- 支付比例
- 付款描述
- 支付时限
- 备注
- 涉及位置

付款描述如有多条，前端直接换行显示，不默认折叠。

建议一行内信息过长时，保持表格列宽稳定，单元格内部换行，避免横向滚动过重。

### 4.6 质保明细

质保明细允许 LLM 返回更多自定义字段。

设计上建议采用“固定核心字段 + 动态扩展字段”的方式：

固定核心字段：

- 质保期
- 服务范围
- 响应时效
- 现场支持
- 违约金
- 更新升级
- 维护文档
- 质保期满安排

动态字段：

- LLM 识别出的其他质保相关承诺、限制、例外条件或特殊说明

前端展示建议：

- 核心字段优先展示
- 动态字段追加在“其他条款”或“补充信息”区域
- 每个字段尽量保留涉及位置，便于人工复核

### 4.7 Excel 下载配置

允许用户在下载前选择是否包含“合同问题”Sheet。

默认建议：

- 默认包含合同问题 Sheet
- 若无合同问题，Sheet 中显示“未发现问题”
- 用户可取消勾选“包含合同问题 Sheet”

下载配置建议放在下载按钮附近，形式为：

- 复选框：包含合同问题 Sheet
- 主按钮：下载 Excel

### 4.8 设置页

设置页采用单列折叠列表，不采用固定双栏布局，便于后续增加更多配置项。

当前折叠项：

| 折叠项 | 内容 |
|--------|------|
| 模型服务配置 | OpenAI-compatible Base URL、API Key、模型名称 |
| 关于平台 | 当前版本、文件范围、部署形态、数据说明 |

若用户未配置模型服务，且服务端也未提供环境变量，合同分析页应提示用户先到设置页配置模型服务，不返回假数据或演示数据。

## 5. 交互流程

```text
进入合同分析页
  ↓
上传合同文件
  ↓
前端校验格式和大小
  ↓
上传成功后进入解析中
  ↓
LLM 返回结构化结果
  ↓
展示问题提示、付款计划、质保明细、置信度
  ↓
用户查看原文定位或条款位置
  ↓
用户选择是否包含问题 Sheet
  ↓
下载 Excel
```

## 6. 当前已确认决策

| 问题 | 决策 |
|------|------|
| 导航栏形式 | 采用左侧导航 |
| Logo | 飞渡 Logo 使用占位符 |
| 结果页是否保留原文定位 | 保留“合同原文定位 / 条款位置”入口 |
| 问题严重程度 | 支持错误、警告、提示三级 |
| 付款描述多条展示 | 前端直接换行显示 |
| 质保字段 | 允许 LLM 返回更多自定义字段 |
| Excel 问题 Sheet | 下载前允许用户选择是否包含 |
| LLM 置信度 | 展示解析置信度，并提示人工复核 |
| 导航收缩 | 支持左侧导航收缩 / 展开 |
| 导航占位页 | 未完成模块也可点击跳转，展示待开发占位内容 |
| 设置页结构 | 单列折叠列表 |
| 模型未配置 | 提示用户先到设置页配置模型服务 |

## 7. 后续原型迭代建议

下一版可交互原型建议覆盖以下页面状态：

- 初始上传态
- 格式错误 / 大小超限态
- 上传中态
- 解析中态
- 解析成功态
- 解析失败态
- 原文定位侧边抽屉
- 下载配置弹窗或下载确认区

后续如果进入正式开发，建议先实现静态前端交互，再接入后端 API。
