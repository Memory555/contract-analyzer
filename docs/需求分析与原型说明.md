# 合同智能分析平台：需求分析与原型说明

来源文档：`D:\feidu\工具1\合同分析平台_需求文档.md`

## 1. 平台定位

这是一个轻量级单合同智能分析平台，V1.0 的核心闭环是：

上传合同文件 → 文档解析 → LLM 结构化提取 → 展示付款计划、质保明细、合同问题 → 下载 Excel。

V1.0 不包含用户登录、权限体系、合同在线编辑、多合同批量对比和法律效力审查。

## 2. 核心用户与使用场景

目标用户为合同管理人员或项目助理。

典型任务：

- 快速提取合同中的分阶段付款计划。
- 集中查看质保期、响应时效、违约金、服务范围等质保信息。
- 发现条款矛盾、数值缺失、逻辑冲突和定义模糊等问题。
- 下载一份包含三个 Sheet 的 Excel 结果表，用于后续跟进。

## 3. 信息架构建议

V1.0 采用“左侧导航 + 顶部标题区 + 主内容工作区”的后台工作台结构。当前默认模块为“合同分析”，后续可扩展工作台、问题审查、导出中心和设置等模块。

当前“合同分析”页面内部仍采用单页工作流：

1. 左侧导航：工作台、合同分析、问题审查、导出中心、设置。
2. 顶部标题区：页面路径、任务说明、版本状态。
3. 上传区：拖拽或点击上传，显示格式、大小限制和异常提示。
4. 处理状态区：上传进度、解析中提示、失败重试。
5. 结果摘要区：文件信息、解析状态、问题数量、LLM 解析置信度、下载按钮。
6. 问题提示区：优先展示高风险问题，保留原文定位 / 条款位置入口。
7. 付款计划明细表：阶段、比例、付款描述、支付时限、备注、涉及位置。
8. 质保明细表：核心字段优先展示，并允许 LLM 返回更多自定义字段。
9. Excel 下载配置：允许用户选择是否包含“合同问题”Sheet。

## 4. 交互状态

| 状态 | 用户看到的界面 |
|------|----------------|
| 初始 | 上传区突出显示，结果区不展示或显示空状态 |
| 文件校验失败 | 上传区红色提示，说明格式不支持或大小超限 |
| 上传中 | 上传进度条、文件名、取消/重新选择入口 |
| 解析中 | 骨架屏或加载动画，提示预计 10-30 秒 |
| 解析成功 | 展示问题提示、付款明细、质保明细、LLM 置信度、原文定位入口和下载按钮 |
| 解析失败 | 展示明确错误原因和重新上传按钮 |

## 5. 第一版原型设计重点

第一版低保真原型暂不追求视觉品牌风格，优先确认：

- 平台是否采用可扩展的后台工作台结构。
- 导航栏是否承载后续更多合同、审查、导出、配置类功能。
- 上传区和结果区是否采用同一页面上下结构。
- 合同问题是否需要固定在结果顶部，作为最先关注的信息。
- 付款计划明细采用宽表展示，付款描述多条时直接换行。
- 质保明细采用核心字段 + 动态扩展字段。
- 下载按钮放在任务摘要区，并提供是否包含问题 Sheet 的下载选项。

## 5.1 已确认设计方向

- 飞渡 Logo 暂以占位符展示，后续替换正式品牌资产。
- 平台不做单一工具页面，而采用可扩展导航栏形式。
- 当前默认功能为“合同分析”，但导航中预留后续扩展能力。
- 视觉风格由设计侧自由发挥，优先保证美观、清晰、专业。
- 展示 LLM 解析置信度，并提示 AI 结果需人工复核。

建议导航结构：

| 一级导航 | 当前用途 | 后续扩展可能 |
|----------|----------|--------------|
| 工作台 | 展示最近分析、任务状态、数据概览 | 多合同任务、待处理事项 |
| 合同分析 | 当前核心页面，上传合同并查看结构化结果 | 批量分析、历史记录 |
| 问题审查 | 聚合条款矛盾、数值缺失、逻辑冲突 | 人工复核、风险分级 |
| 导出中心 | Excel 下载与历史导出 | 模板管理、批量导出 |
| 设置 | 模型、字段、Excel 模板配置 | Prompt 配置、权限配置 |

## 6. 已确认设计决策

| 问题 | 决策 |
|------|------|
| 导航栏采用左侧导航还是顶部导航 | 采用左侧导航，便于后续扩展更多模块 |
| 是否保留合同原文定位 / 条款位置 | 保留，在结果页提供入口 |
| 合同问题严重程度 | 支持“错误 / 警告 / 提示”三级 |
| 付款描述多条展示方式 | 前端直接换行显示 |
| 质保明细字段 | 允许 LLM 返回更多自定义字段 |
| Excel 是否包含问题 Sheet | 下载前允许用户手动选择 |
| 是否展示 LLM 解析置信度 | 展示，并配合人工复核提示 |

## 7. 后续可交互原型范围建议

建议先制作以下 5 个前端状态：

- 初始上传态
- 文件校验失败态
- 上传/解析中态
- 解析成功态
- 解析失败态
- 原文定位侧边抽屉
- 下载配置区域

如需进一步贴近实际业务，可补充“扫描件不支持”与“无合同问题”的两个特殊状态。
