平台是什么
合同智能分析平台是一款面向合同审查人员的辅助工具，核心能力是把 DOCX 合同文件交给 AI 模型自动提取和检查，输出结构化的付款计划、质保明细和风险提示，降低人工逐页翻阅的成本。
🔍
合同分析
上传 DOCX → AI 自动提取付款计划（阶段、比例、时限）、质保明细（核心 + 扩展字段）、合同问题（error / warning / info 三级）；支持单份和批量（最多 20 份），串行执行、单份失败不影响其余
📊
导出中心
单合同 Excel 导出；批量汇总 Excel（5 个 Sheet：概览、付款计划、质保、问题、失败清单）
💬
反馈管理
对分析结果提交"有帮助"或"有问题"反馈；问题可选 5 种分类；另提供"我的云端总览"统计卡片 + 分页列表
⚙️
设置
配置模型服务（Base URL / API Key / 模型名）、联通测试、切换亮/暗色主题、清除本地数据
🛠️

💬 方式二：直接对话上传（最简）

适合：临时使用、无需安装任何工具、任何支持文件上传的 AI 对话

⚡
核心优势：零配置、零安装。直接在 ChatGPT、Claude、Gemini、Kimi 等任何对话中上传文件，配合一段提示词即可分析。
1
打开任意支持文件上传的 AI 对话（ChatGPT、Claude、Gemini、Kimi 等）
2
上传 DOCX 合同文件，并粘贴以下提示词：
# 通用提示词（可复制到任何 AI 对话中） 请分析这份合同，提取以下结构化信息，以 Markdown 表格输出： 1. 付款计划：阶段、名称、比例、触发条件、时限、备注 2. 质保明细：质保期、响应时效、违约金、服务范围、质保期起算日、质保金退还条件、质保范围排除项 3. 合同问题：检查条款矛盾、数值缺失、逻辑冲突、定义模糊，按 ERROR / WARNING / INFO 分级 注意： - 比例总和应为 100%，如果不符请标注 - 质保期如有多种表述（如"3年"和"验收后1年"），请指出矛盾 - 输出格式：Markdown 表格 + 问题列表
3
AI 直接读取文件内容并输出分析结果，无需任何额外配置
👤 用户示例
使用 contract-analyzer-skill 分析这份采购合同，重点关注付款条款和质保条款。请以表格形式列出付款计划（阶段、比例、触发条件、时限），以及质保明细（质保期、响应时效、违约金）。同时检查是否有条款矛盾或数值缺失。[上传 采购合同.docx]
⚠️
局限性：直接对话方式依赖 AI 自身对文件的理解能力，结构化程度不如 Skill 版本稳定。适合快速查看，不保证与平台版本输出完全一致。

技术栈
层面技术说明
前端框架 Next.js 15（App Router）+ React 19 + TypeScript 单页多面板架构，Serverless API Routes 兼做后端
AI 调用 OpenAI SDK（Responses API + JSON Schema Structured Outputs） 兼容任何 OpenAI 协议的服务
DOCX 提取 mammoth.js 浏览器端提取，无需后端
Excel 导出 ExcelJS 前端直接生成，无需后端
云端数据库 Neon PostgreSQL（新加坡节点） 反馈数据持久存储 + 用户数据隔离
本地数据库 Dexie / IndexedDB 历史记录、导出记录、反馈提交状态缓存
容器化 Dockerfile（三阶段构建，standalone 输出） 部署到 CloudBase 云托管
Skill 版本 Node.js + mammoth + openai SDK AI 平台工作流，无需浏览器，跨平台运行

Skill 版本（v5）限制

限制项说明
仅支持单份不支持批量分析，每次只能分析一份合同
仅支持 DOCX不支持 PDF、DOC、扫描件（需先用其他工具转换）
无历史记录分析结果不保存，每次需重新分析
AI 平台依赖Skill / 对话方式依赖 AI 平台的模型能力和文件解析能力

模型响应延迟

一次完整的合同分析流程中，延迟主要受以下因素影响：
📄 合同长度
文本越长，模型输入 token 越多，推理时间越长
5页 ≈ 5-10s · 20页 ≈ 15-30s
🧠 模型服务
不同模型 / 不同提供商的推理速度差异很大
GPT-4.1-mini: 3-8s/页
📝
总结：单份合同分析典型耗时 5-30 秒，主要由模型推理决定。Skill 版本为 AI 平台工作流，无浏览器开销，响应速度与平台版本相当。
