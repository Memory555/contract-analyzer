# 合同智能分析平台 - 需求文档

> 版本：V1.0  
> 日期：2026-06-17  
> 状态：初稿

---

## 一、项目概述

### 1.1 项目背景

当前合同管理中存在以下痛点：

- 合同付款计划分散在正文中，人工提取耗时易错；
- 质保条款散布于多个章节（付款条款/售后服务/验收交付），难以完整提取；
- 合同前后条款矛盾（如质保期不一致）不易被人工审查发现；
- 缺乏统一的结构化输出格式，后续逐条跟进困难。

### 1.2 项目目标

构建一个**轻量级合同智能分析平台**，实现：

1. 用户上传合同文件（支持 PDF / DOC / DOCX）；
2. 系统自动调用 LLM 提取**付款计划明细**、**质保明细**及**合同内容问题**；
3. 结果在界面直观展示，并提供 Excel 下载（一张表，含三个子表：付款明细 + 质保明细 + 合同问题）。

### 1.3 项目范围

| 包含 | 不包含 |
|------|--------|
| 合同文件上传与格式兼容 | 在线编辑合同原文 |
| LLM 驱动的内容提取与问题检测 | 合同法律效力审查 |
| 付款计划 + 质保明细结构化展示 | 多合同批量对比 |
| 双表 Excel 下载 | 用户注册/登录/权限体系 |
| 前端界面 + 后端 API | 移动端 APP |

## 三、功能需求

### 3.1 合同上传模块

**F-01 文件上传**

| 项目 | 说明 |
|------|------|
| 触发 | 用户点击上传区域或拖拽文件 |
| 格式 | PDF / DOC / DOCX |
| 大小限制 | 单文件 ≤ 20MB |
| 数量限制 | 每次上传 1 份合同（V1.0 不支持批量） |
| 反馈 | 上传进度条 + 成功/失败提示 |
| 异常处理 | 格式不支持 → 提示仅支持 PDF/DOC/DOCX；大小超限 → 提示限制 |

**验收标准：**
- 拖动 PDF/DOC/DOCX 文件至上传区，可正常开始上传
- 拖动 .txt / .jpg 文件，收到"不支持的文件格式"提示
- 上传 25MB 文件时，收到文件大小超限提示

---

### 3.2 合同解析模块

**F-02 LLM 内容提取**

| 项目 | 说明 |
|------|------|
| 输入 | 上传的合同文件（解析为文本后传入） |
| 输出 | 三类结构化信息（见下文 3.3） |
| 处理时效 | 预期 ≤ 30 秒返回结果 |
| 异常处理 | LLM 调用超时或失败 → 界面提示"解析失败，请重试" |

**F-03 文档解析预处理**

系统须先对上传文件做格式转换，统一为纯文本后再送入 LLM：

| 文件类型 | 处理方式 |
|---------|---------|
| PDF | 提取文本（优先使用文本层，若扫描件则提示"当前不支持扫描件"） |
| DOC | 转换为 DOCX → 提取文本 |
| DOCX | 直接提取文本（含段落 + 表格） |

**验收标准：**
- 上传示例合同后，10-30 秒内返回提取结果
- 若后端 LLM 不可用，前端显示明确错误提示而非空白

---

### 3.3 结果展示模块

#### 3.3.1 付款计划明细（F-04）

提取合同中的分阶段付款信息，以卡片或表格形式展示：

| 字段 | 说明 | 示例 |
|------|------|------|
| 阶段序号 | 1 / 2 / 3… | 第一阶段 |
| 阶段名称 | 合同原文的阶段描述 | 合同签订后 |
| 支付比例 | 占合同总额的百分比 | 30% |
| 触发条件 | 付款的前置条件（支持多条） | ① 收到业主方首付款 ② 乙方提供增值税专票 |
| 支付时限 | 满足条件后的支付窗口 | 60 个工作日 |
| 备注 | 原文中其他关联信息 | 背靠背付款 |

#### 3.3.2 质保明细（F-05）

提取合同中的质量保证与售后服务条款：

| 字段 | 说明 | 示例 |
|------|------|------|
| 质保期 | 起算点 + 时长 | 验收合格之日起 1 年 |
| 服务范围 | 质保期内免费服务的覆盖项 | 技术指导、免费升级、故障修复 |
| 响应时效 | 按等级分列的响应/解决时间 | 重大故障：0.5h 响应，3h 解决 |
| 现场支持 | 现场到达时限 | 24 小时内到达 |
| 违约金 | 超时或违约的罚则 | 一般故障 1000 元/次 |
| 更新升级 | 版本更新/补丁的提供义务 | 7 个工作日内无条件提供 |
| 维护文档 | 文档要求 | 维护记录 + 年度总结报告 |
| 质保期满 | 期满后安排 | 协助交接，续签补充协议 |

#### 3.3.3 合同问题提示（F-06）

LLM 应在提取过程中识别以下类型问题：

| 问题类型 | 说明 | 示例 |
|---------|------|------|
| 条款矛盾 | 不同条款对同一事项定义不一致 | 5.4 条款写 3 年质保期，7.1 条款写 1 年质保期 |
| 数值缺失 | 关键数值留空 | 合同金额填写"￥ 元" |
| 逻辑冲突 | 条款逻辑上互相矛盾或不可执行 | 分期比例相加 ≠ 100% |
| 定义模糊 | 关键术语缺乏定义 | "合理期限内"未量化 |

以**高亮标签**（警告 / 提示）形式在结果页顶部展示。

**验收标准：**
- 上传包含质保期矛盾的合同，结果顶部应出现红色"条款矛盾"提示
- 付款明细表格至少包含阶段、比例、触发条件、支付时限 4 列
- 质保明细表格至少包含质保期、响应时效、违约金 3 类信息

### 3.4 下载模块

**F-07 Excel 下载（一张表，三个子表）**

| 项目 | 说明 |
|------|------|
| 格式 | .xlsx |
| 内容 | **Sheet 1：付款计划明细** / **Sheet 2：质保明细** / **Sheet 3：合同问题** |
| 文件名 | `合同分析结果_{原文件名}.xlsx` |
| 表头 | 中文，加粗，浅蓝色背景 |
| 列宽 | 自适应内容，避免截断 |
| 触发 | 点击"下载结果"按钮 |

**Sheet 3（合同问题）字段：**

| 字段 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 问题类型 | 条款矛盾 / 数值缺失 / 逻辑冲突 / 定义模糊 |
| 严重程度 | 错误 / 警告 |
| 问题描述 | 具体问题说明 |
| 涉及位置 | 合同中的条款位置 |

**验收标准：**
- 下载的 xlsx 包含三张 Sheet，可正常用 Excel/WPS 打开
- Sheet1 包含付款计划所有字段，Sheet2 包含质保明细所有字段，Sheet3 包含合同问题列表
- 若无合同问题，Sheet3 显示"未发现问题"
- 文件名包含原合同文件名，可区分不同合同的结果

### 4.2 交互流程

```
用户进入页面 → 上传合同文件
                    ↓
              显示加载动画（"正在分析合同中…"）
                    ↓
              LLM 返回结果
                    ↓
           ┌────── 展示结果 ──────┐
           ↓                      ↓
      问题提示区               付款明细表
     (如有问题)              质保明细表
           ↓
   用户点击"下载 Excel" → 浏览器触发下载
```

### 4.3 状态说明

| 状态 | 界面表现 |
|------|---------|
| 初始 | 上传区居中，无结果区 |
| 上传中 | 上传区显示进度条 |
| 解析中 | 结果区显示骨架屏/加载动画 + "正在分析合同中，预计 10-30 秒…" |
| 解析成功 | 结果区展示问题提示 + 双表 + 下载按钮 |
| 解析失败 | 结果区展示错误提示 + "重新上传"按钮 |
| 格式不支持 | 上传区红色边框 + 错误提示 |

## 五、技术方案建议

### 5.1 技术选型

| 层级 | 技术选项 | 说明 |
|------|---------|------|
| 后端框架 | Python（FastAPI） / Node.js（Express） | 轻量级，部署简单 |
| 文档解析 | python-docx / PyPDF2 / pdfplumber | 提取文本 |
| DOC→DOCX | LibreOffice headless 或 win32com（Windows） | 旧格式转换 |
| LLM | 调用大模型 API（如 OpenAI / 通义千问 / 文心） | 核心推理能力 |
| 前端框架 | React / Vue 3 / 纯 HTML | 对用户透明，单页即可 |
| Excel 生成 | openpyxl（Python） / ExcelJS（Node.js） | 双 Sheet 输出 |
| 部署 | 单机 Docker 或直接运行 | V1.0 无需集群 |

## 六、非功能需求

| 需求项 | 指标 |
|--------|------|
| 响应时间 | 从文件上传完成到结果展示 ≤ 30 秒 |
| 并发 | V1.0 支持单用户即可 |
| 可用性 | 互联网连接正常时可用 |
| 安全性 | 上传文件仅用于本次分析，不持久存储（或定时清理） |
| 兼容性 | Chrome / Edge 浏览器最新两个大版本 |
| 容错性 | LLM 返回格式不合法时，fallback 显示原文摘要 + 错误提示 |

## 八、附录

### A. 参考合同模板

本次分析的参考合同：`【软件】飞渡采购合同模板-V2.0`，已确认包含：
- 第五条：付款计划（三阶段：30% / 65% / 5%）
- 第七条：质保明细（响应时效、违约金、服务范围等）
- 已发现：5.4 条与 7.1 条质保期矛盾（3 年 vs 1 年）

### B. 术语对照

| 术语 | 说明 |
|------|------|
| 付款计划 | 合同约定的分阶段付款条件与比例 |
| 质保明细 | 质量保证期内的服务承诺、响应标准和违约罚则 |
| 条款矛盾 | 同一合同中两个或多个条款对同一事项给出不一致定义 |
