# v1 版本交付说明

版本：v1.0.0  
日期：2026-06-18  
应用目录：`frontend`

## 1. 版本定位

v1 是合同智能分析平台的第一个可部署 Demo 版本，目标是完成端到端验证：

- 上传 DOCX 合同。
- 在浏览器端提取合同文本。
- 调用 OpenAI 或 OpenAI-compatible 模型服务生成结构化分析结果。
- 展示合同问题、付款计划、质保明细和置信度。
- 支持原文片段复核和 Excel 导出。
- 支持 Vercel 与 Cloudflare Workers 两套部署路径。

## 2. 已交付程序

- `frontend/app/page.tsx`：主工作台、导航、上传、分析结果和设置页面。
- `frontend/app/api/analyze/route.ts`：合同分析 API。
- `frontend/app/api/model-test/route.ts`：模型服务连通性测试 API。
- `frontend/lib/docx.ts`：DOCX 文本提取。
- `frontend/lib/excel.ts`：Excel 导出。
- `frontend/lib/local-db.ts`：浏览器本地历史记录。
- `frontend/vercel.json`：Vercel 部署配置。
- `frontend/wrangler.jsonc`：Cloudflare Workers 部署配置。
- `frontend/open-next.config.ts`：OpenNext Cloudflare 适配配置。

## 4. 本地验证

进入前端目录：

```bash
cd frontend
npm install
npm run build
```

本地开发：

```bash
npm run dev
```

访问：

```text
http://localhost:3000
```

## 5. 部署入口

### Vercel

- Root Directory：`frontend`
- Build Command：`npm run build`
- Install Command：`npm install`
- Output Directory：默认

### Cloudflare Workers

- Root Directory：`frontend`
- Build Command：`npm run cf:build`
- Deploy Command：`npx wrangler deploy`
- 非生产分支上传命令：`npx wrangler versions upload`

## 6. 环境变量

```text
OPENAI_API_KEY=你的模型服务 Key
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4.1-mini
NEXT_PUBLIC_DEMO_MODE=true
```

说明：

- `OPENAI_API_KEY` 应配置为部署平台 Secret。
- `OPENAI_BASE_URL` 可替换为 OpenAI-compatible 服务地址。
- 页面设置中填写的模型配置优先于服务端环境变量。

## 7. v1 范围限制

当前版本暂不支持：

- PDF。
- DOC。
- 扫描件 OCR。
- 用户登录。
- 云端历史记录。
- 多合同批量分析。
- 独立后端任务队列。

## 8. v2 迭代建议

建议 v2 优先处理：

- PDF / DOC 文件支持。
- 长合同分段抽取与结果合并。
- 更严格的结构化输出校验和失败重试。
- 批量分析与导出中心。
- 云端历史记录和用户权限。
- 更细的合同审查规则配置。
