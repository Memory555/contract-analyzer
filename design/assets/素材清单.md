# 原型与开发素材清单

## 需要业务侧提供或确认

- 平台名称是否固定为“合同智能分析平台”。
- 是否有飞渡品牌色、Logo、字体规范或内部系统 UI 规范。
- 1-3 份可用于测试的脱敏合同样例，最好包含：
  - 正常付款计划；
  - 质保条款完整样例；
  - 已知条款矛盾或数值缺失样例。
- 期望导出的 Excel 表头顺序、字段命名和样式要求。
- 合同问题类型与严重程度的最终枚举。
- 是否需要展示企业内部免责声明，例如“AI 结果仅供参考，需人工复核”。

## 可选视觉素材

- 产品 Logo 或部门标识。
- 内部系统截图，用于统一控件风格。
- Excel 导出样例或既有台账模板。
- 典型合同文件命名规则。

## 设计侧默认假设

- V1.0 面向桌面端浏览器，优先兼容 Chrome 和 Edge。
- 使用克制的办公系统风格，强调可读性和表格信息密度。
- 不做营销式首页，进入页面后直接上传合同。
