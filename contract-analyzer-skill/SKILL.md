# 合同智能分析 Skill

## 功能描述

当用户提供合同文件或合同文本时，自动分析并提取：

1. **付款计划** — 各阶段名称、付款比例、触发条件、付款时限、备注。
2. **质保明细** — 质保期、响应时效、违约金、服务范围、起算日、退还条件、排除项。
3. **合同问题** — 条款矛盾、数值缺失、逻辑冲突、定义模糊、履约风险，按 ERROR / WARNING / INFO 分级。

支持的输入形态：

| 输入 | 说明 |
|------|------|
| DOC / DOCX | Word 合同文档 |
| PDF | 文本层 PDF 或扫描 PDF |
| JPG / JPEG / PNG | 合同扫描图、截图或照片 |
| 文本 | 用户直接粘贴的合同内容 |

## 触发条件

- 用户上传合同文件并提及“合同”“分析”“审查”“风险”“付款”“质保”等关键词。
- 用户明确请求：“分析这份合同”“提取付款计划”“检查质保条款”“找出合同问题”等。
- 用户提供合同文本后直接说：“看看这个”“帮我审一下”“提炼重点”。

## 工作流

### 步骤 1：读取合同内容

根据输入形态获取可分析文本：

- 对可复制文本的文档，优先提取正文、表格、页眉页脚中的文字。
- 对扫描件或图片，先识别图片中的文字，再进入合同分析。
- 对疑似识别质量较差、文本过短、页码缺失、图片模糊的内容，在分析结果中提示人工复核。
- 如果文件加密、损坏、空白或无法识别，提示用户重新提供清晰文件或粘贴合同文本。

### 步骤 2：结构化分析

使用以下系统提示词进行分析，要求 AI 以结构化 JSON 输出：

```text
你是一个严谨的合同审查助手。请只根据合同文本进行分析，不要编造合同中不存在的信息。

分析维度：
1. 付款计划：提取所有付款阶段，包含阶段序号、名称、付款比例、付款前置条件、付款时限、备注、条款位置、原文片段。
2. 质保明细：提取质保期、响应时效、违约金、服务范围、质保期起算日、质保金退还条件、质保范围排除项等，保留条款位置和原文片段。
3. 合同问题：检查条款矛盾、数值冲突、数值待确认、定义模糊、条件缺失、履约风险、法律或合规风险，并按严重程度分级。

严重程度：
- error：重大矛盾、金额或期限冲突、明显法律风险、可能导致无法履约或重大损失的问题。
- warning：表述模糊、条件遗漏、编号缺失、付款或验收条件不充分、责任边界不清。
- info：建议补充、建议优化、需要人工确认但风险较低的问题。

输出要求：
- 所有输出文字使用简体中文。
- 每条问题尽量引用具体条款编号或位置。
- 每条问题给出可执行的修改建议。
- 不能确认的信息必须标注“待确认”，不要擅自补全。
```

## 输出要求

- 付款比例使用百分比，如 `30%`，不要只给小数。
- 时限尽量统一为“X 个工作日 / X 日 / X 月 / X 年”格式。
- 问题描述必须引用具体条款编号、页码或位置；无法定位时标注“位置待确认”。
- 修改建议要具体可执行，避免只写“建议完善”。
- 对扫描件、图片、低清晰度文件，应提示 OCR 或识别质量可能影响结果。
- 保持客观中立，不替代法律意见，不做超出合同文本的判断。

## 边界处理

- 如合同无付款计划，说明“未找到明确付款计划”，并提示人工确认是否在附件中。
- 如合同无质保条款，说明“未找到明确质保条款”。
- 如付款比例合计不为 100%，在付款计划和合同问题中同时提示。
- 如同一事项存在多个期限、金额、比例或起算点，优先标为 ERROR 或 WARNING，并列出冲突来源。
- 如检测到方括号、空白、占位符、`XX`、`待定` 等，标为待确认问题。
- 如文本明显来自 OCR 且存在错字或断句，降低置信度并提示人工复核。
